# Tic-Tac-Toe AI

A simple Tic-Tac-Toe game built using Python where a human player competes against an AI. The AI uses the Minimax algorithm to make optimal moves, making it impossible to beat.

## Features

- Play against an AI
- Intelligent AI using the Minimax algorithm
- Detects win, lose, and draw conditions
- User-friendly command-line interface
- Input validation for player moves

## Technologies Used

- Python 3

## Project Structure

```
Tic-Tac-Toe AI/
│── game.py
│── README.md
```

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python game.py
```

## Sample Gameplay

```
 1 | 2 | 3
-----------
 4 | 5 | 6
-----------
 7 | 8 | 9

Enter your move: 5
```

The AI will automatically make its move after yours.
